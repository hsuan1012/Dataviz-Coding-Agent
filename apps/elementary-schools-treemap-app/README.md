# 臺灣國民小學校別圖集（Zoomable Treemap）

**Live site：<https://elementary-schools-treemap-app.vercel.app>**

以 zoomable treemap 呈現 **103–114 學年度全臺約 2,700 所國民小學**的規模分布：
**縣市 → 鄉鎮市區 → 學校**三層下鑽，面積＝學生人數或專任教師人數（可切換），
底部時間軸可逐年播放（呈現方式比照世界發展數據分析平台）。

- 資料來源：教育部統計處「國民小學校別資料」
  （[data.gov.tw dataset 6240](https://data.gov.tw/dataset/6240)，
  原始檔 `{yy}_basec.csv`×12 年，本地副本在 `data/raw/`）
- 互動範例參考：amCharts multilevel tree map

## 五個變項

縣市名稱、鄉鎮市區、學校名稱、學生人數（1–6 年級男＋女加總）、專任教師人數（男＋女）。

## 功能

- **三層 zoomable treemap**（D3.js）：一次顯示兩層（當前層＋下一層預覽）；
  點區塊下鑽、點空白處或麵包屑返回。
- **縣市定色（LCH 配色，指導老師 8/14 調色盤方法）**：22 縣市在 LCH（d3.hcl）
  色相環均分各得一色、彩度固定走柔和路線；群組標題帶用較深明度——參數集中於
  styleDictionary `treemapLch`，深淺主題各一組。
- **區塊深淺＝生師比**（指導老師 8/17 回饋）：同縣市色相下，區塊明度對應該單位
  生師比——比值越小越淺、越大越深（無專任教師＝最深端）；色階定義域取當年
  全體學校的 p10–p90 分位數夾擠（抗小校離群值，跨層級同一把尺），
  麵包屑列右側有圖例說明。
- **縣市區塊間隔寬於內部間隔**（老師 8/14 縮至 6/3/1.5 後，8/17 回饋再縮：
  全國 2.5px／縣內 1.25px／最內 0.6px）。
- **量值切換**：學生人數｜專任教師人數兩顆獨立按鈕；tooltip 恆並列兩值＋生師比；
  與 English、深色模式共四顆膠囊鈕集中於右上同列。
- **KPI 條**跟著當前層級（全國/縣市/鄉鎮）變動（緊湊單列：標籤左、數字右）。
- **誠實註記**：量值為 0 的學校（面積為零本就隱形）排除於圖外，頁尾資料來源行
  尾註記數量＋「展開名單」小鈕彈出浮動名單視窗（再點或點空白處關閉；
  例：磊川華德福有 140 名學生、0 名專任教師）。
- 方向 A 冷石板＋青綠**深淺雙主題**（**預設深色**，指導老師 8/17 回饋）；
  RWD（小螢幕維持點按互動）。
- **中英雙語**：右上膠囊鈕切換（中文模式顯示「English」、英文模式顯示「中文」），
  介面全字串（含 tooltip、無障礙標籤、頁尾註記）雙語；**資料名稱亦雙語**——
  縣市＝官方英文名（New Taipei City…）、鄉鎮＝漢語拼音＋官方例外
  （Tamsui、Lukang、Lyudao）、學校＝前後綴翻譯＋核心名漢語拼音
  （如 Municipal Xiulang Elementary School；機器轉寫、非官方名）；
  搜尋同時支援中文（臺/台異體）與英文名。
- **視窗貼合**：桌機（≥1000×640）整頁塞進視窗不出捲軸，treemap 以 ResizeObserver
  量測容器彈性填滿剩餘高度；小裝置退回正常捲動版面。
- **左側欄（常駐）**：①搜尋——學校/鄉鎮/縣市名稱
  （支援臺/台異體字）與**年份**（輸入「108」跳該學年；自畫透明底 ±1 箭頭，
  原生 spinner 在深色模式會冒亮白色塊且底色不可自訂，root 並設 `color-scheme`
  讓其餘原生控件隨主題），結果點擊即下鑽並高亮；
  ②**競速長條圖**（指導老師 8/17 回饋）——當前層級各單位依量值排名，
  長條色＝所屬縣市色相；播放年份時名次與長條長度以動畫追逐互換
  （穩定 key＋絕對定位 FLIP）；hover 高亮 treemap、點擊下鑽；
  ③**歷年趨勢 sparkline 跟隨當前選取單位**（指導老師 8/17 回饋）——
  停在全國顯示全國趨勢、下鑽縣市/鄉鎮顯示該層趨勢、點選學校（treemap 區塊
  或側欄列）顯示該校趨勢；**當前學年標記點**（垂直參考線＋數值標籤）隨時間軸
  與播放平滑移動（桃園縣/市跨年視為同一縣市、裁併年份留斷點）。
- **年份時間軸（103–114）**：播放/暫停膠囊鈕＋accent 進度滑桿＋大字年份
  （同世界發展數據分析平台的 TimeControls）；切年時 treemap 以學校代碼為 key
  跨年 morph；非當前年資料 lazy-load（Vite 逐年分包）；下鑽狀態在切年後
  自動退到仍有效的路徑（如 103 年無「桃園市」→ 回全國）。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + vite build
npm test           # vitest（資料層對帳 33 tests）
```

### ETL（原始 CSV → 階層 JSON）

```bash
cd etl
uv run --with pandas python build_hierarchy.py          # 產出 src/data/schools_{103..114}.json + years.json
uv run --with pandas --with pytest python -m pytest -q  # 對帳測試 54 tests
```

對帳基準（pandas 獨立實跑鎖定）：114 學年 2,663 校／22 縣市／學生 1,165,258／專任教師 99,724。

### 跨年資料處理決策（誠實揭露）

- **103–108 檔沒有「鄉鎮市區」欄**：以 109–114 的學校代碼→鄉鎮對照回填（109 年優先，
  以現制行政區呈現）；回填不到的（109 前裁併校，103 年 31 校→108 年 0 校）放入該縣市
  「（鄉鎮未載明）」偽鄉鎮，縣市與全國總數與原始檔完全一致，不默默剔除。
- **103 年桃園尚未升格**：縣市名稱保留歷史原貌「桃園縣」；色彩以縣市代碼（03）對齊，
  桃園縣/桃園市跨年同色。
- 臺中、臺南、高雄因縣市合併各有兩個縣市代碼，ETL 以縣市名稱合併。
- 「學年度」欄 110 年才出現，一律以檔名為準；109 檔數值欄帶尾隨空白已 strip。
