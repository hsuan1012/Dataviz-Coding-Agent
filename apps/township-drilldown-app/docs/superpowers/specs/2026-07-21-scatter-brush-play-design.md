# 設計文件：關係頁 linked brushing ＋ 全域年份播放

日期：2026-07-21
分支：`scatter-brush-play`（僅本地，未推 GitHub；老師確認方向後再推）

## 背景與動機

老師 7/17 提供的 bokeh crossfilter 範例包含兩個核心互動：
1. 視覺通道自由指派（7/20 已完成上線）
2. **linked selection**（框選點集合、跨視圖連動）——本次補上

另加入計畫書參考網站 Gapminder 的年份自動播放，讓現有補間動畫「自己動起來」。

## 功能一：全域年份播放

### 行為

- ▶ 鈕置於年份分頁列（YearTabs）最前面，兩個外殼（方向A／Taste）皆有。
- 按 ▶ 後每 **1.2 秒**前進一年；走到最後一年**自動停止**（Gapminder 慣例）。
- 在最後一年按 ▶ ＝從第一年重新播放。
- 播放中手動點任一年份＝立即暫停並跳至該年。
- 切換分頁（主畫面↔關係）不中斷播放。

### 實作

- 不寫新動畫：計時器到點呼叫現有 `onYear`，地圖色塊漸變、排名長條流動、
  泡泡游動全部沿用既有補間。
- 播放邏輯抽成純函式 reducer（輸入：目前年份、年份清單；輸出：下一年、
  是否停止），置於 `src/lib/`，先寫測試再實作（TDD）。
- 計時器生命週期在 App 層管理（`useEffect` 清理），避免殘留 interval。

## 功能二：散布圖框選 → 迷你地圖連動

### 行為

- 散布圖加 d3.brush；**放開框選當下**把框內鄉鎮算成**鎖定名單**
  （`Set<towncode>`）。語意是「鎖名單」不是「鎖區域」：之後切年份／播放，
  名單不變，觀察同一群鄉鎮游動。
- 選取後：名單內泡泡維持原色，名單外降透明度（對區域分類色與連續色階
  兩種顏色模式皆適用）。
- 切換 X/Y/顏色/大小通道**不清除**名單（crossfilter 精神：同一群換座標系續看）。
- 清除方式：點「清除」鈕，或在散布圖上點空白處／框選空集合。

### 迷你地圖

- 關係頁右側嵌 ~220px 迷你台灣鄉鎮地圖：名單內填主題青綠、其餘淺灰。
- 重用已載入的 `taiwan_townships.geojson` 與主地圖投影／金馬 inset 邏輯。
- 上方顯示「已選 N 鄉鎮｜清除」。
- 純顯示用途：迷你地圖本身不可點擊、不可下鑽（YAGNI）。

### 實作

- 選取狀態提升至 App（與 `scatter` 通道狀態同層）。
- 「框範圍＋當年資料 → 鄉鎮名單」抽成純函式，置於 `src/lib/`（TDD）。
- 迷你地圖為獨立元件 `MiniMap`，props 進 geojson＋名單，無內部狀態。

## 不做的事（YAGNI）

- 不做「鎖定框選區域、逐年重算成員」語意（已確認不要）。
- 不做歷年軌跡線（trail）。
- 迷你地圖不做互動（點擊／hover／下鑽）。
- 不做循環播放（loop）。

## 驗證計畫（沿用五層驗證）

1. **程式層**：tsc 0 錯；vitest 既有 56 項維持全綠。
2. **單元測試（新增）**：播放 reducer（前進／末年停止／重播）、框選集合
   計算（含空集合、邊界點）、MiniMap 路徑產生。
3. **互動層（Playwright 新增情境)**：
   - 按 ▶ → 年份自動前進、至末年停止；
   - 播放中點年份 → 暫停；
   - 框選 → 泡泡透明度分層、迷你地圖高亮數＝「已選 N」；
   - 框選後切年份 → 名單不變；
   - 切通道 → 名單不變；清除 → 全數還原；
   - 既有 19 項自動化驗證維持全 PASS。
4. **視覺層**：截圖（播放中、框選態、清除後）人工比對。
5. **人工審查**：localhost 實際操作走查。

## 實作備註（最終審查後補記）

實作與本文兩處有意的偏離，記錄以利對齊：

- **播放計時器生命週期**：實際置於 `YearTabs` 元件內管理（非「App 層 `useEffect`」，
  §功能一原文所述）。效果等價（unmount／依賴變化都會清 interval），差別在於
  外殼切換（方向A↔Taste）會整個卸載重掛 `YearTabs`、播放因此停止；但分頁切換
  （主畫面↔關係）不影響 `YearTabs` 的掛載，播放不中斷，符合原訂行為。
- **鎖定名單型別**：實作為鄉鎮 `FULLNAME` 的 `string[]`（非 §功能二原文所述
  `Set<towncode>`）。改用全名字串是因為地圖／散布圖／迷你地圖三處既有代號都
  已用 `FULLNAME` 對照（非 towncode），沿用同一鍵可省一層轉換；`data.test.ts`
  已有測試鎖住這個介面形狀，防止之後不小心換型別。
