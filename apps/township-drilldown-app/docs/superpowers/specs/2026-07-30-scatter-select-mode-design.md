# 散布圖「選取模式」與版面調整

## 背景

老師/使用者要求：大小圖例移到左上（跟色彩圖例併排）、清除鈕移到右上；新增「選取」按鈕控制框選開關；
單擊泡泡也能選取；雙擊清除選取（確認為既有「剔除到空自動清除」行為，沿用不改）。

**設計修正（同日，實作中途，共兩輪）**：
1. 原規劃「清除」是無條件「清空整個選取」的一次性按鈕（無選取時停用）。使用者看到雛型後澄清：
   「清除」應該跟「選取」一樣是拖曳框選模式，只是效果相反——框選到的泡泡從名單「移出」，而不是
   整個名單一次清空。進一步確認「選取」的框選也應改成累加（原本是取代整個名單），讓「選取」＝加、
   「清除」＝減，兩者對稱互斥。
2. 但單顆泡泡的點擊手勢不比照框選分裂成加/減兩套：使用者澄清「不管是選取還是清除按鈕，單擊就是
   選取、雙擊就是取消選取」——單擊/雙擊固定不分模式（單擊一律加入、雙擊一律移出，與既有「雙擊
   剔除」完全同一套邏輯），只有框選（拖曳）才依選取/清除模式而有加/減之分。

以下內容為兩輪修正後的最終設計。

## 版面

圖例列（`Scatter.tsx` 的 `legendRow`）：色彩圖例＋大小圖例都在左側；右側「選取」「清除」兩顆按鈕，
互斥的框選模式切換鈕（視覺完全對稱，同一套 `aria-pressed` 開關樣式）。原本在 `TasteShell.tsx`
圖表下方的一次性清除鈕移除，功能整合進「清除」模式。圖下方白話解說/操作提示文字同步更新用字（見下）。

## 互動模式

- `Scatter.tsx` 內部新增 `mode: "select" | "clear" | null`（`useState`，純 UI 狀態，不進 App/reducer）。
- 預設 `null`：拖曳空白處不框選、單擊泡泡無反應（一般瀏覽狀態，不會誤觸）。
- 按「選取」→ `mode="select"`；再按一次或按「清除」→ 切換；兩鈕**互斥**（開一個自動關另一個，
  同一個拖曳手勢不能同時做相反的兩件事）。工具開關式，做完一次框選/單擊動作不會自動退出模式。
- **單顆泡泡的點擊手勢不分模式**（`mode="select"` 或 `"clear"` 皆同，任一模式開啟時才有反應）：
  - 單擊＝把該泡泡**併入**目前選取名單（`[...new Set([...(selected ?? []), township])]`，已在名單中
    則 no-op，不重複加入），呼叫 `onSelect`，一併退回全國（沿用既有 `applyBrush`）。
  - 雙擊（`onExcludeTown`）＝從名單移出，**完全不受 `mode` 影響**：任何時候（含兩模式都關閉時）
    雙擊已選中的泡泡都會將它從名單移除，移除後名單空了自動清除＋回全國（既有行為，7/24 已上線）。
- **框選（拖曳）才依模式分加/減**，這是「選取」跟「清除」兩顆鈕唯一的行為差異：
  - `mode="select"` 時拖曳框選＝框內鄉鎮**併入**目前選取名單
    （`[...new Set([...(selected ?? []), ...rectNames])]`）。
  - `mode="clear"` 時拖曳框選＝框內鄉鎮從目前選取名單**移出**（`selected.filter(t => !rectNames.has(t))`），
    移出後名單空了傳 `null`。
  - 兩者都整包算好新名單後呼叫既有 `onSelect`／`applyBrush`（接收「完整新名單」、退回全國、
    空名單存 `null`），reducer 本身不用改，呼叫端算好聯集/差集再傳入即可。
  - 拖曳一個空框（無實際拖曳距離，`d3.brush` 的 `ev.selection` 為 `null`）＝不動作（不清空、不影響
    現有名單），只重置框選視覺。
- 「清除」鈕在完全沒有選取（`selected` 為 `null`/空）時停用（沒東西可清）；名單被清空後
  （不論透過清除模式框選、雙擊剔到空，或其他途徑例如點麵包屑回全國）也會自動退出清除模式
  （`useEffect` 監看 `selected`，避免停用鈕卻仍顯示 `aria-pressed=true` 的怪狀態）。
- 全清所有選取：沒有專用按鈕，維持既有捷徑——點麵包屑回「全國」（`applyView` 既有規則：
  回全國層＝選取清空），或在清除模式下框選涵蓋全部已選泡泡的範圍。

## 文案更新

- 框選 coach mark（圖內提示章，僅未選取時顯示）：引導「按上方『選取』後可拖曳框選或單擊泡泡」。
- 圖下方無選取時提示（`TasteShell.tsx`）：補上「選取」「清除」兩種框選模式＋單擊加入/雙擊移出的簡短說明。
- 圖下方已選取時提示：說明「選取」框選＝加入、「清除」框選＝移出、單擊泡泡皆加入/雙擊皆移出；
  第二行改為「回全國即可清空選取」。

## 測試影響

`scripts/verify-brush-play.mjs` 需要整段重寫框選/清除相關流程（原本「按清除鈕＝立即清空」的假設
已不成立）：
- 兩模式都關閉（預設）時拖曳無反應。
- 按「選取」開啟後拖曳框選＝累加進名單（用兩次不重疊框選＋檢查前一批仍在名單中，驗證「累加」
  而非「取代」）。
- 單擊泡泡＝累加進名單（含重複點擊同一顆不重複加入），任一模式開啟時皆同一行為（不分選取/清除）。
- 按「清除」（與「選取」互斥，開一個關另一個）後拖曳框選＝從名單移出框內項目（用「先移出一部分、
  再移出剩餘」兩步驟驗證「累減」而非「一次清空」）；清除模式下單擊泡泡仍是加入（不是移出）。
- 「清除」鈕無選取時停用；名單被框選移到空時自動退出清除模式（`aria-pressed` 應變回 `false`）。
- 雙擊在 `mode` 三種狀態（`null`/`select`/`clear`）下都正常運作，一律移出，不受模式影響。
- 空框（無拖曳距離）不影響既有名單。

## 不做（YAGNI）

- 不做 shift+click 等其他選取手勢。
- 不改動 `applyBrush`／`applyExclude` 既有 reducer 函式簽名與規則（呼叫端組好完整名單再傳入即可）。
- 不另做「一鍵清空全部」的第三顆按鈕：回全國麵包屑已有此效果，重複沒必要。
