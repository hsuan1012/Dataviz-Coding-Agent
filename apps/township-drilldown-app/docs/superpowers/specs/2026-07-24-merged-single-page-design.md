## 語意：指標歸屬（B 案配套）

- **X 軸＝全頁「當前指標」**：地圖塗色、排名依據、標題皆由 `scatter.x` 導出。
  導出函式 `xToIndicator(x): { indicator, deathCause }`（`death_c*` → indicator=death＋該死因；
  五指標 → 該指標＋deathCause=death）。App 不再持有 indicator/deathCause state。
- 「顏色」通道只管散布圖泡泡（區域=分類色、連續變數=色階），不影響地圖。
- 村里層 X 無資料（死亡率/死因）：**不改 X**，地圖塗色走 `effectiveIndicator` 降級
  （密度）＋notice 提示；散布圖照常（鄉鎮層資料不受下鑽影響）。排名欄村里層維持現狀（無資料訊息）。

## 語意合一：下鑽＝整縣選取（B 案，五條規則）

狀態＝`{ view, selected }`，全部進純 reducer（`src/lib/mergedSelect.ts`，TDD）：

1. **點地圖縣市**（全國層）＝下鑽＋整縣選取：`view=drillToCounty`、`selected=該縣全部鄉鎮`；
   散布圖高亮該縣、其餘調暗；排名=縣內前五。
2. **散布圖框選**＝只選取不下鑽：`selected=名單`、`view=NATION`（已下鑽時自動退回全國）。
   「最後動作贏」。框空＝清除＋回全國。
3. **返回全國＝清除選取**（對稱：清除鈕＝回全國）。麵包屑回縣層＝`selected=該縣鄉鎮`。
4. **縣層點鄉鎮**＝進村里層＋`selected=[該鄉鎮]`（散布圖高亮單點）。
5. **雙擊剔除＝編輯選取不動 view**（已下鑽時剔除保持下鑽）；剔到空→回未選取＋回全國。
   年份/通道切換不動 `{view, selected}`。hover 雙向預覽保留於全國層。

實作路徑：App 的 `onView` 統一走 reducer（Choropleth 點擊、麵包屑、hash 深連結共用同一入口，
深連結 `#/臺北市` 進來即帶整縣選取）；Scatter 的雙擊改走新 prop `onExcludeTown`（與 onSelect 分流，
避免剔除誤觸「回全國」規則）。

## 地圖高亮（全國層縣級聚合 × 鄉鎮名單的解法）

全國層主地圖維持**縣級加權聚合面量圖**（誠實聚合不變）。選取名單以**疊加層**表現：
選中鄉鎮的 path 以 accent 描邊＋半透明填色疊在縣級面量圖上（geo.features 本就含全部鄉鎮形狀；
迷你地圖 fillMap/selected 邏輯移植）。縣/村里層照現有繪製，選取交集疊加。
金馬 inset 框、clipPath、投影三件套（fit/clip/繪製集合）沿用既有教訓。MiniMap 元件退役（檔案保留）。

## 取捨（明說）

- 原迷你地圖「點多縣累加 toggle」犧牲：點地圖=單縣下鑽；跨縣名單只能框選。`countySelect.ts` 退役。
- 排名欄不跟框選名單連動（跟層級走），避免狀態機爆炸；後續可加。
- hover 預覽只在全國層。

## 版面演進補記（實作日當天，使用者 wireframe v2–v13 迭代）

初版三欄(散布圖45%|地圖30%|排名25%)經使用者連續回饋演進為 **Bento Box 定版**：
左側指標欄(=X 軸捷徑)回歸；主區=地圖卡左 1/3 貫穿全高(視覺焦點/篩選器)、

互動語言(accent token,雙主題)。**互動語意(B 案五條規則)與指標歸屬(X=全頁指標)不變。**
村里層降級同 spec 微調：patchChannels({x:"density"})+notice(X 即全頁指標,降級一體適用)。

## 教訓預防（7/24 merged-page 分支三個震盪 bug）

- ResizeObserver 用 `contentRect` 不用 gBCR（進場動畫污染量測）。
- 地圖欄寬不得由等高回路決定（切斷 高→寬→高 flex 循環，欄寬定值/比例）。
- 版面改動後檢查捲軸出沒是否造成寬度抖動（scrollbar-gutter）。
