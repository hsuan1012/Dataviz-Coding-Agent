# 設計文件：關係頁迷你地圖放大＋雙向互動

日期：2026-07-22
分支：本地開發，**不 push GitHub**（老師確認後再推）

## 背景與動機

老師 7/21 審閱後回饋：「關係」頁的迷你地圖可以再大一點。使用者進一步希望：

1. 迷你地圖高度與泡泡圖（散布圖）一樣高。
2. 迷你地圖從純顯示升級為**雙向互動**：點選地圖區域，泡泡圖同步反應。

現況（7/21 版）：`MiniMap.tsx` 寬 260px、純顯示、選中＝強調色／未選＝淺灰；
選取名單只能由散布圖框選產生。

## 需求確認（2026-07-22 與使用者逐題確認）

| 題目 | 決定 |
|---|---|
| 點選單位 | **點任一鄉鎮＝選取整個縣市**（368 鄉鎮太小難點準；與下鑽頁縣市概念一致） |
| 選取語意 | **toggle 累加**：點一縣＝整縣併入名單；再點同縣＝整縣移出；可多縣並存、可與框選結果聯集 |
| 懸停預覽 | **要**：滑過某縣→地圖該縣描邊強調＋散布圖該縣泡泡同步描邊（不改鎖定名單，移開即復原） |
| 地圖塗色 | **跟隨泡泡顏色**：顏色通道＝區域→區域分類色；＝指標→同一條連續色階（mini choropleth） |

## 設計

### 版面（等高）

- 關係頁散布圖與迷你地圖同列 flex，`align-items: stretch`。
- 迷你地圖 svg：`height: 100%` ＋ `aspect-ratio: 800/900`（沿用主圖 viewBox 比例），
  寬度自動 ≈ 高度 × 0.89。散布圖維持 `maxHeight: 56vh`。
- 窄螢幕維持現有 `flex-wrap` 行為；迷你地圖設合理 `min/max` 防跑版。
- 「已選 N 鄉鎮／清除」與操作說明文字保留在地圖上／下方；說明文字補「點地圖
  任一縣市可整縣加入或移出」教學句（維持狀態式說明：未選教起手、已選教後續）。

### 塗色（與泡泡同步）

- Scatter 依目前顏色通道算出「鄉鎮 → 填色」對應（`Map<FULLNAME, string>`）傳給
  MiniMap：區域＝`regionColor` 分類色；指標＝`ramp(colorNorm(value))` 連續色階。
- 資料缺漏的鄉鎮＝淺灰（`t.border`）。
- 切年份／切顏色通道時地圖塗色跟著更新（與泡泡同一份資料來源 `scatterPoints`）。

### 選取表現

- 有鎖定名單：名單內＝原色＋強調色描邊；名單外＝低不透明度淡化
  （與泡泡 0.7 vs 0.12 的視覺邏輯一致）。
- 無名單：全部原色、無描邊。

### 點選（雙向互動核心）

- 點地圖任一鄉鎮 → 以 `countyOf(feature)` 取所屬縣市 → toggle 整縣：
  - 該縣**所有**鄉鎮已在名單內 → 整縣移出（其餘名單保留）；
  - 否則 → 整縣（全部鄉鎮）併入名單（聯集）。
- toggle 後名單為空 → 視同清除（`selected = null`，與既有清除語意一致）。
- 純函式 `toggleCounty(selected, countyTowns)` 置於 `src/lib/countySelect.ts`，TDD。
- 名單型別沿用既有 `string[]`（FULLNAME），不動 App 層介面形狀。

### 懸停預覽

- MiniMap 滑過鄉鎮 → 取所屬縣 → 該縣全部鄉鎮描邊強調（地圖端）。
- 同時 Scatter 該縣的泡泡加強調描邊（散布圖端）。
- hover 狀態（`string | null`，縣名）放在 **Scatter 層**（不進 App：不與年份
  播放等全域狀態糾纏；切分頁自然歸零）。
- 泡泡的縣別判定：以 `FULLNAME` 前綴對照（FULLNAME＝縣名＋鄉鎮名，與
  `countyOf` 同一來源規則）。
- 懸停不改鎖定名單；不與 tooltip 衝突（tooltip 屬泡泡 mousemove，維持不動）。

### 不變的部分

框選、點空白清除、「清除」鈕、切年份／切通道保留名單、年份播放、
金馬 inset（含烏坵排除）——行為全部不動。

## 不做的事（YAGNI）

- 不做單一鄉鎮逐個點選（已確認：點縣市整縣）。
- 不做 Shift 微調模式。
- 迷你地圖不做下鑽、不做縮放。
- 不做地圖端框選。

## 驗證計畫（沿用五層驗證）

1. **程式層**：tsc 0 錯；vitest 既有測試全綠。
2. **單元測試（新增）**：`toggleCounty`（併入／整縣移出／部分選取時併入／
   移出後空名單→null）、鄉鎮→填色對應（區域色／連續色階／缺資料淺灰）。
3. **互動層（Playwright 新增情境）**：
   - 點某縣 → 「已選 N」＝該縣鄉鎮數、泡泡淡化分層、地圖淡化分層；
   - 再點同縣 → 整縣移出（名單歸零→清除態）；
   - 框選一群＋點另一縣 → 名單＝聯集；
   - 懸停某縣 → 地圖與泡泡描邊出現、移開消失；
   - 切顏色通道 → 地圖塗色跟著變（區域色↔色階）；
   - 既有自動化驗證維持全 PASS。
4. **視覺層**：截圖（等高版面、點選態、懸停態、色階塗色態）AI 終審——
   特別檢查金馬 inset 點擊命中與等高版面在窄視窗的表現（澎湖／烏坵前例）。
5. **人工審查**：localhost 實際操作走查。
