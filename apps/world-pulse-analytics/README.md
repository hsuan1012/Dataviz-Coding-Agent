# 世界發展數據分析平台

**🔗 線上網站：https://world-pulse-analytics.vercel.app**

> 開發過程使用 Claude Code 協助。

仿 Gapminder Tools 的互動網頁：左側國家勾選清單、中間泡泡圖＋三欄全球競賽長條圖，
右側 globe.gl 3D **choropleth 地球儀**（Natural Earth 110m 國界填色，老師 8/3 回饋），
支援 1950–2019 年份滑桿與播放動畫、深淺色主題切換與中英雙語介面。視覺套用
township-drilldown-app 的 Direction A 設計系統（Noto Serif/Sans TC、青綠強調色、冷石板中性色）。

## 功能

- **泡泡圖四通道下拉（頁首）**：X 軸／Y 軸／顏色／大小皆可自由切換指標
  （人均所得、平均餘命、總人口、兒童死亡率、總生育率），X＝Y 時另一軸自動 disable 防呆；
  大小通道採各指標獨立半徑範圍，避免定義域窄的指標泡泡糊成一團。
- **框選選取與清除模式**：按「選取」後在泡泡圖上拖曳框選一批國家（單擊泡泡加入，
  已選的泡泡再單擊一次可移出），按「清除」再框選則是移出；選取後其餘國家灰階淡化。
- **滾輪縮放＋拖曳平移**（8/4 取代原本的放大鏡框選按鈕；8/7 改對數空間版）：在圖上滾動＝
  以游標為錨點縮放（上滾放大、下滾縮小），放大後拖曳圖面＝平移可視範圍，雙擊空白處一次還原。
  log 軸（人均所得/總人口）的縮放/平移在**對數轉換空間**計算且縮放中保留對數刻度
  （1-2-5 系列動態刻度）——游標下的國家縮放時像素級釘住不跳；「縮放中切線性刻度」與
  「游標定點」在三個數量級的對數軸上數學上不可兼得，故不採用。縮放範圍外的泡泡乾淨裁掉。
- **使用說明彈窗**：控制列「使用說明」按鈕開合，列出選取／清除框選模式與滾輪縮放的操作方式
  與目前已選國家數，並隨通道切換同步顯示對應的狀態說明文字。
- **choropleth 地球儀雙向連動**：泡泡圖框選/清除會即時反映到地球儀（未選國家灰化），
  點擊地球儀上的國家也會 toggle 該國的選取狀態，兩邊狀態同步；國名標籤中英兩行顯示；
  南極洲/格陵蘭等 10 個不在統計清單的地區以中性灰裝飾顯示並於卡片下方註明。地球儀初始
  視角以**台灣為中心**（老師 8/11 回饋）。
- **左側國家勾選清單預設收合**（老師 8/11 回饋）：一開始只顯示五大洲標題與各洲國家數，
  點洲別列展開才看得到該洲的完整國家清單。
- **「全不選」狀態改中性配色，不清空畫面**（老師 8/11 回饋）：左側按「全不選」後，
  地球儀、散布圖、長條圖三個連動視圖不再各自變空白——地球儀改呈現白底黑邊界的
  中性世界地圖、散布圖泡泡改淺灰色、長條圖改深灰色，全部國家/資料仍照樣畫出，
  只是不套用洲別/指標語意色，維持「準備好開始篩選」的畫面骨架。
- **地球儀顏色跟隨「顏色」通道**（老師 8/7 回饋）：顏色通道選「區域」時維持洲別色；
  選人均所得/平均餘命等指標時，地球儀改用與泡泡圖同一套青綠連續色階按當年值填色
  （深淺主題各自的色階），該年缺值的國家以無資料灰顯示；hover 國家標籤同步顯示
  該指標當年數值；播放中地球儀顏色跟著年份連續變化。
- **通道連動排名卡**：X／Y／顏色／大小四個通道各自的「全球前 5」排名卡，
  跟著目前選擇的指標即時更新，顏色＝區域時改顯示無排名數值的說明。
- **三欄全球競賽長條圖**：人均所得／平均餘命／總人口三指標各自的全球前 5 名長條圖，
  隨年份滑桿/播放動畫即時換名次動畫；上榜名單與數值刻意不受左側國家勾選清單影響，
  彈窗與排名卡皆標明為「全球排名」（長條的顏色會跟著「全不選」狀態切換成中性深灰，
  見上方說明，但這只影響配色，不影響排名本身）。
- **年份滑桿與平滑播放動畫**（老師 8/7 回饋）：1950–2019 播放／暫停（老師 8/11 回饋：
  終點收在最後一個完整年份，忽略 2020 年後部分指標只剩推估值的資料缺口；
  初始停在 2019＝最新一年先看現況，於終點按播放自動從 1950 重跑），
  年份可直接鍵入跳轉（±1 箭頭為自畫透明底按鈕——原生 number spinner 在深色
  模式會冒亮白色塊且底色不可自訂；`:root` 並設 `color-scheme` 讓其餘原生控件
  隨主題渲染），
  繪圖區內有光學置中的大年份浮水印。播放以 requestAnimationFrame 連續推進小數年份
  （每秒 2.5 年，總時長不變），資料層對前後兩年逐指標線性內插——泡泡沿資料路徑
  連續平滑移動，不再逐年跳格；年份顯示（滑桿/浮水印/輸入框）維持整數，
  缺值年份不做內插捏造（該國該年照缺值規則隱藏）。
- **兩個新指標**：兒童死亡率（0–5 歲，每千活產）、總生育率（每位婦女平均生育數），
  資料來源見下方「資料來源」。
- **深淺色主題**：地球儀卡片右上角切換；洲別色/色階/灰化色皆有深色版
  （數值沿用 township-drilldown-app 的 styleDictionary dark tokens）。
- **中英雙語**：頁首 English/中文 切換,介面文字/國名標籤/說明彈窗全數跟隨。
- **矮視窗降級**：視窗高 ≤860px 時解鎖整頁捲軸、內容列改固定高度（比照
  township-drilldown-app 的高度斷點做法），桌機高度不受影響。

## 開發

```bash
npm install
npm run dev
```

`src/data/*.json` 已經產生好並提交在版本庫中，一般開發不需要重跑。
只有在 `supervisor/data/global/gapminder_core3.csv`（位於本 repo 之外的
同層 `supervisor/` 目錄）有更新時，才需要執行：

```bash
npm run prepare-data   # 從 supervisor/data/global/gapminder_core3.csv 重新產生 src/data/*.json
```

## 測試

```bash
npm run test           # Vitest 單元測試（14 檔 169 測試：資料處理、年份內插、色階、播放、
                        # 勾選(含臺/台異體字搜尋)、地球儀填色、通道/框選/滾輪縮放(對數空間)/刻度稀疏化、狀態機、排名、i18n）
npm run typecheck      # TypeScript 型別檢查
npm run build          # 正式建置
npm run verify:scatter # Playwright 實跑 20 斷言：四通道/框選/防呆/播放/矮視窗降級/
                        # 滾輪縮放與拖曳平移(含 clamp 釘邊回歸)/使用說明彈窗
```

## 資料來源

- `supervisor/data/global/gapminder_core3.csv`（Gapminder，CC-BY 4.0），
  篩選 `all_three == 1`（1950–2050 年、195 國）。詳見同目錄
  `gapminder_core3_缺失值說明.md` 對缺值結構與推估值分界的完整說明。
- 兒童死亡率、總生育率兩個新指標取自 Gapminder fasttrack
  （[open-numbers/ddf--gapminder--fasttrack](https://github.com/open-numbers/ddf--gapminder--fasttrack)，
  CC-BY 4.0），下載到 `data-src/`：

  ```bash
  npm run download-data   # 下載 fasttrack 兩份 datapoints CSV 到 data-src/
  npm run prepare-data    # 重新產生 src/data/*.json（含 gapminder_core3.csv 與 fasttrack 兩指標）
  ```
